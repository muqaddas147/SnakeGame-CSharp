# 🐍 Snake Game in C#

A classic Snake Game developed using **C# and Windows Forms** in Visual Studio as a programming project to demonstrate Object-Oriented Programming (OOP) concepts.

## 📌 Project Overview

This project is a desktop-based Snake Game where the player controls a snake to collect food, earn points, and avoid obstacles. The game includes different food types, difficulty settings, and a high-score system.

## ✨ Features

- Classic Snake gameplay
- Object-Oriented Programming (OOP)
- Regular food and Golden Food
- Obstacles
- Score tracking
- Difficulty settings
- Pause and Game Over functionality
- High-score saving system
- Windows Forms graphical interface

## 🛠️ Technologies Used

- C#
- .NET Framework
- Windows Forms
- Visual Studio
- Object-Oriented Programming (OOP)

## 📂 Project Structure

- `GameObject.cs` – Abstract base class for game objects
- `Snake.cs` – Snake movement and behavior
- `Food.cs` – Regular food
- `GoldenFood.cs` – Special food with extra points
- `Obstacle.cs` – Game obstacles
- `GameBoard.cs` – Game board management
- `GameManager.cs` – Main game logic
- `Form1.cs` – Game interface
- `HighScoreManager.cs` – High-score management

## 🎮 How to Run

1. Download or clone this repository.
2. Open `SnakeGame.csproj` or the solution file in Visual Studio.
3. Build the project.
4. Run the application.
5. Enjoy the game!
